# C 语言课程练习

广东工业大学《程序设计》课程练习代码，按上课进度随手记录。

## 编译与运行

```bash
gcc 文件名.c -o 文件名
./文件名
```

也可以用 Dev-Cpp 直接打开 `.c` 文件按 F11 编译运行。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| 九九乘法表.c | 打印 9×9 乘法表 |
| 判断素数.c | 判断输入的数是否为素数 |
| 整数的位数.c | 求一个整数有几位 |
| 最大公约数.c | 求两个整数的最大公约数 |
| 选择排序.c | 用选择排序对数组排序 |
| 闰年判断函数.c | 把闰年判断封装成函数 |
| 阶乘和.c | 求阶乘的累加和 |
| 阶乘的运算(有函数版).c | 阶乘计算，用函数封装 |
| 读取最多10个整数的平均数，并求出大与平均数的数.c | 读入最多 10 个整数，求平均值并输出大于平均值的数 |
| 输出字符串里的大写字母.c | 从字符串中提取出大写字母 |
| 未命名2.c | 指针数组练习：输入下标输出对应字符串 |
| 实验用.c | 用 sizeof 测试 int 占用的字节数 |
